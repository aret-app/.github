# Aret 🏔️

**An open-source, privacy-first, offline-first companion for hiking and the mountains.**

Plan routes, record your hikes with the phone's own sensors, and keep your maps and tracks with you even without signal. Built on OpenStreetMap and open data, with no ads and no trackers.

| Repository | What's inside |
|---|---|
| [aret-ios](https://github.com/aret-app/aret-ios) | iOS app (SwiftUI, MapLibre, offline-first) |
| [aret-backend](https://github.com/aret-app/aret-backend) | Rust services: identity, tracks & sync, route planning |
| [aret-maps](https://github.com/aret-app/aret-maps) | Tile pipeline, map styles, terrain and routing data |
| [aret-infra](https://github.com/aret-app/aret-infra) | Deployment and operations |
| [aret-docs](https://github.com/aret-app/aret-docs) | Architecture, decisions (ADRs), privacy documents |
